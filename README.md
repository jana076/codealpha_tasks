## Tasks Completed

### Task 1 - Web Scraping
Scraped quotes, authors, and tags from quotes.toscrape.com using BeautifulSoup and requests, then stored the collected data in a CSV file.

**Tools:** Python, requests, BeautifulSoup, pandas

### Task 2 - Exploratory Data Analysis (EDA)
Performed exploratory analysis on the Titanic dataset: checked and handled missing values, calculated survival rates by sex and class, detected outliers using the IQR method, and computed correlations between variables.

**Tools:** Python, pandas, numpy, seaborn, matplotlib

### Task 3 - Data Visualization
Built a 4-panel dashboard to visually analyze the Titanic dataset: survival rate by class, age distribution, age vs fare relationship, and fare distribution by class.

**Tools:** Python, matplotlib, seaborn

### Task 4 - Sentiment Analysis
Classified a set of product reviews into positive/negative/neutral using the VADER sentiment lexicon, and visualized the resulting sentiment distribution.

**Tools:** Python, NLTK (VADER), pandas, seaborn
